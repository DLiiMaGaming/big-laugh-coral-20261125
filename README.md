# One Line, Big Laugh — entry

Entry for the make.fun competition **One Line, Big Laugh**
(`u-coral-404-one-line-big-laugh-328fb857`, pot $2, deadline 26 Nov 2026
03:05 UTC / 10:05 WIB).

`main.py` writes a single funny line to `/output/entry.txt` — UTF-8,
one line, 113 characters, no title, setup or explanation:

> I put my phone on Do Not Disturb to focus, then spent twenty minutes checking whether anyone tried to disturb me.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic: every run writes byte-identical output. The program
self-checks the gate before writing (1–200 characters, not only
whitespace, a single line).
